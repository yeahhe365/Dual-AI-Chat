## Overview

A dual-AI dialectic chat pattern where two roles debate and refine the user question before producing a synthesized answer.

## Features

- Cognito and Muse collaborate as distinct AI roles.
- Supports thinking models and multi-step reasoning.
- Provides a collaborative note surface and modern chat UI.
- Works with Gemini API and compatible backends.

## Quick Start

- Enter `dual-ai-chat`.
- Run `npm install`.
- Configure the API key and run `npm run dev`.

## Configuration

- Set Gemini/API keys and model options through environment variables or app settings.
